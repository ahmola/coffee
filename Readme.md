# Microservice with SpringBoot 2

## Overview
This project contains a collection of microservices with springboot version 3.4.5 and jar 17 implements of coffee shop

## Microservice Description
1. Config Server
  - endpoint : 8888
2. Service Discovery Server(Netflix Eureka)
  - endpoint : 8761
3. API Gateway Service
  - endpoint : 8080
4. Beverage Service
  - endpoint : 8090
5. Customer Service
  - endpoint : 8091
6. Order Service
  - endpoint : 8092
7. Payment Servcie
  - endpoint : 8093
8. Notification Server(Kafka)
  - endpoint : 9092
9. Cache Server(Redis)
  - endpoint : 6379
